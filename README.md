
# Pet Adoption Website 

A simple and beginner-friendly pet adoption website built using **HTML and CSS**.

##  Features
- Card-based layout for pets
- Beige aesthetic theme
- Responsive design for mobile screens
- Hover effects on cards and buttons

## 🛠 Tech Stack
- HTML
- CSS

## 🎯 Purpose
This project was created to practice frontend fundamentals such as:
- Flexbox layout
- CSS styling
- Responsive design
- Git & GitHub workflow
